# Dewashish Tiwari — academic portfolio

Public academic website for [Dewashish Tiwari](https://dewashishtiwari.github.io), an atmospheric scientist working across air pollution, climate extremes, environmental health, and socioeconomic vulnerability.

## Pages

- Home
- About
- Research
- Projects
- Public CV

The site is a dependency-free static build for GitHub Pages. It supports responsive layouts, keyboard navigation, reduced-motion preferences, and light/dark themes.

## Privacy

The public CV intentionally excludes phone numbers, residential information, and referee contact details. A complete CV is available directly from Dewashish on request.
